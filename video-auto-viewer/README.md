# ファミリア Google活用動画 自動視聴テスト

[ファミリア Google活用動画アプリ](https://familia-workspace-video-app-31130680210.asia-northeast1.run.app/) を、
**アプリ本体とは完全に別のシステム**として外側からブラウザ操作で試験するツールです（Playwright 使用）。

- アプリのコード・APIには触れません。人が操作するのと同じく画面をクリックするだけです。
- 再生は**等倍・シークなし**で行い、アプリ側の「実視聴」計測をそのまま検証します。
  そのため 1 本あたり「動画の長さ × 80%」程度の実時間がかかります。

## 試験する流れ

1. トップ画面で未視聴の「おすすめ動画」を選ぶ
2. アプリ内プレーヤーで再生（止まったら再生ボタンを押し直す）
3. 「実視聴」が 80% に達し「視聴を記録できます」になるまで待つ
4. タグ・自由コメントを入力して「視聴登録する」を押す
5. 「視聴を登録しました。」と今月の視聴数の増加を確認

結果は `reports/<実行日時>/result.json` と各段階のスクリーンショットに保存されます。

## 準備（初回のみ）

Node.js 20 以上が入った PC で実行します。

```bash
cd video-auto-viewer
npm install
npx playwright install chromium
npm run login
```

`npm run login` でブラウザが開くので、「Googleでログイン」から試験用アカウント（@touki.bz）で
ログインしてください。トップ画面が表示されると自動で終了し、ログイン状態が `.auth/profile` に保存されます。

> Google から「安全でないブラウザ」と言われる場合は、PC に入っている Chrome を使ってください:
> `PW_CHANNEL=chrome npm run login`（以降の `npm run watch` にも同じ指定を付けます。Windows の PowerShell では `$env:PW_CHANNEL="chrome"; npm run login`）

`.auth/` にはログイン情報が入るため、他人と共有したりコミットしたりしないでください（`.gitignore` 済み）。

## 実行

```bash
# 1本視聴して登録（既定タグ「基本を確認できた」、コメント「【自動視聴テスト】」）
npm run watch

# 5本、画面を表示しながら
npm run watch -- --count 5 --headed

# タグ・コメントを指定
npm run watch -- --tag すぐ使ってみたい --tag 新しい発見があった --comment "【テスト】操作確認"

# 登録ボタンは押さずに 80% 到達までを確認
npm run watch -- --dry-run

# オプション一覧
npm run watch -- --help
```

| オプション | 内容 |
| --- | --- |
| `--count N` | 視聴登録する本数（既定 1） |
| `--tag タグ` | 付けるタグ（複数可）。`すぐ使ってみたい` / `新しい発見があった` / `みんなに見て欲しい` / `基本を確認できた` / `ちょっと気になる` / `今の業務では使わなさそう` |
| `--comment 文字列` | 自由コメント（`""` で無し） |
| `--video 文字列` | タイトルにこの文字列を含む動画だけを対象にする |
| `--max-minutes N` | これより長い動画はスキップ（既定 40 分） |
| `--dry-run` | 80% 到達まで確認し、登録はしない（途中経過はアプリ側に保存される） |
| `--headed` | ブラウザ画面を表示する |

## 注意

- 登録したタグ・コメントは「視聴した人の声」などで他の社員にも表示されます。
  試験であることがわかるよう、コメントに【テスト】等を入れることをおすすめします。
- 途中で止めた場合も、アプリ側で進捗が保存されます。次回は続きから再生されます。
- アプリの画面構成（クラス名・文言）が変わると動かなくなることがあります。
- ログインの有効期限が切れたら `npm run login` をやり直してください。
