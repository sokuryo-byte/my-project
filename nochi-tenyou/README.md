# 農地転用 見積・調査支援システム（Googleスプレッドシート＋GAS）

社内メンバーが農地転用の「見積・調査依頼」を入力するWebフォームです。
入力内容をスプレッドシートに保存し、ルールベースで概算見積を表示し、
「見積調査依頼」ボタンで担当行政書士へ Google Chat 通知を送ります。
詳細調査・正式見積は人が行う前提です（AIによる自動判定はしません）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `src/Config.gs` | **設定はすべてここ**（金額・Webhook URL・選択肢・列定義・シート名） |
| `src/Setup.gs` | 初期セットアップ（シート作成）、スプレッドシートのメニュー、通知テスト |
| `src/Repository.gs` | 保存処理（案件一覧への追記、ID採番、マスタ読込） |
| `src/Estimate.gs` | 概算見積の計算（ルールベース） |
| `src/Notify.gs` | Google Chat への通知 |
| `src/WebApp.gs` | `doGet()`、画面から呼ばれるAPI、入力の整形・チェック |
| `src/Index.html` | フォーム画面（HTML） |
| `src/Stylesheet.html` | 画面のデザイン（CSS） |
| `src/JavaScript.html` | 画面の動き（入力・見積プレビュー・送信） |
| `src/appsscript.json` | マニフェスト（タイムゾーン、Webアプリ公開設定） |

## セットアップ手順

1. Googleドライブで新しいスプレッドシートを作成する（名前例：`農地転用案件管理`）。
2. メニュー **拡張機能 > Apps Script** を開く。
3. `src/` の各ファイルを同名で作成して内容を貼り付ける。
   - `.gs` は「スクリプト」、`.html` は「HTML」で作成（拡張子は付けずに `Index`, `Stylesheet`, `JavaScript`）。
   - `appsscript.json` は **プロジェクトの設定 >「appsscript.json」マニフェスト ファイルをエディタで表示する** をONにして上書き。
4. Google Chat でWebhookを発行する：通知を受けたいスペースを開き **アプリと統合 > Webhook を追加** → URLをコピー。
5. `Config.gs` の `CHAT_WEBHOOK_URL` に貼り付ける
   （またはプロジェクトの設定 > スクリプト プロパティ に `CHAT_WEBHOOK_URL` として登録。こちらが優先）。
6. エディタで関数 `setupSpreadsheet` を選んで実行 → 権限を承認。
   「案件一覧」「マスタ」シートが作成されます（再実行しても既存データは消えません）。
7. スプレッドシートを再読み込みすると、メニュー **農地転用システム** が出ます。
   **Google Chat 通知テスト** で通知が届くことを確認してください。
8. **デプロイ > 新しいデプロイ > 種類：ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（組織名）内の全員** ← 社内Googleアカウントに限定
9. 発行されたURL（`/exec` で終わる）を社内ポータルに貼る。

> コードを修正した後は **デプロイを管理 > 編集 > バージョン：新バージョン** で更新してください（URLは変わりません）。

## スプレッドシート構成

### 案件一覧

| 列 | 見出し | 内容 |
|---|---|---|
| A | ID | 自動採番（1, 2, 3…） |
| B | 受付日時 | 送信日時 |
| C | 依頼者名 | |
| D | 物件所在地（住所） | 市区町村より後ろの住所 |
| E | 地番 | |
| F | 地目 | 田／畑／田・畑混在／その他 |
| G | 面積（登記地積㎡） | 数値 |
| H | 市街化区域／調整区域 | 市街化区域／市街化調整区域／非線引き区域／分からない |
| I | 農振農用地 | TRUE／FALSE／不明 |
| J | 現況利用 | 例：`駐車場（一部物置あり）` |
| K | 既に転用済み | TRUE／FALSE |
| L | 今後の転用計画 | |
| M | 土地改良区の有無 | はい／いいえ／分からない |
| N | 添付資料の有無 | カンマ区切り 例：`謄本,公図,その他（測量図）` |
| O | 概算見積金額 | 円 |
| P | 見積調査依頼フラグ | TRUE＝依頼（通知あり）／FALSE＝保存のみ |
| Q〜V | 補助列 | 都道府県、市区町村、水利組合・農事組合の有無、見積内訳、入力者、Chat通知結果 |

列を増やすときは `Config.gs` の `CASE_COLUMNS` の**末尾**に追加し、`setupSpreadsheet` を再実行してください。
既存列の途中に挿入・並べ替えはしないでください（過去データと列がずれます）。

### マスタ

| 都道府県 | 市区町村 | 都市計画情報URL | 農振図URL | 備考 |
|---|---|---|---|---|

- 初回セットアップで愛知・岐阜・三重の主な市をサンプル投入します（**URLは空欄**。各自治体のページを確認して入力してください）。
- 行を追加するだけでフォームのプルダウンに反映されます（再デプロイ不要）。
- URLを入れると、フォームで市区町村を選んだときに「都市計画情報を開く」「農振図を開く」リンクが表示されます。

## 概算見積ルール（`Config.gs` で変更）

```
概算見積金額 = 基本報酬 + 各種加算の合計
```

| 区分 | 条件 | 仮の金額 |
|---|---|---|
| 基本報酬 | 市街化区域（届出想定） | 50,000円 |
| 基本報酬 | 市街化調整区域／非線引き区域（許可想定） | 120,000円 |
| 基本報酬 | 区域「分からない」 | 調整区域として仮計算（`FALLBACK_ZONE_FOR_UNKNOWN`） |
| 加算 | 農振農用地「はい」 | +150,000円（農振除外） |
| 加算 | 土地改良区「はい」 | +50,000円（地区除外） |
| 加算 | 転用済み「はい」、または現況が駐車場・宅地・資材置場 | +50,000円（現況是正・事後手続き） |

「分からない」の項目は加算せず、画面に「該当すれば +○円」の注意書きを表示します。
計算はサーバー側（`Estimate.gs`）だけで行い、画面は結果を表示するだけなので、金額変更はConfig.gsの1か所で済みます。

## 壊れにくさのための工夫

- **保存 → 通知** の順で処理。通知に失敗しても案件は残り、`Chat通知結果` 列に失敗理由が記録されます。画面にも「担当者へ直接連絡を」と表示します。
- ID採番〜書き込みは `LockService` で排他制御し、同時送信でもIDが重複しません。
- 入力値はサーバー側で再チェック（必須項目、選択肢外の値の除外、文字数制限）。
- `=` `+` `-` `@` で始まる入力は数式として実行されないよう、先頭に `'` を付けて保存します。
- シートが見つからない場合は「初期セットアップを実行してください」と分かるエラーを返します。

## よくある質問

- **Webアプリで「アクセス権がありません」と出る** → デプロイ設定の「アクセスできるユーザー」が組織内になっているか、利用者が社内アカウントでログインしているか確認。
- **入力者のメールが空になる** → 組織外アカウントでアクセスした場合などは取得できません（仕様）。
- **金額を変えたのに画面に反映されない** → 新バージョンとして再デプロイが必要です。
